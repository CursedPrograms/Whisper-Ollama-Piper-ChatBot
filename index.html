What you need

  • Linux with ALSA (arecord, aplay)
  • Python 3.9+ and ffmpeg
  • Ollama with phi3:mini (or any model)
  • A Piper voice in voices/

Run it

pip install -r requirements.txt
ollama pull phi3:mini
python main.py

Say goodbye to stop.

Make it yours

config.json sets Jenny's personality, the model, your mic and speaker devices and how long it listens.
